## 什么是 MCBECD？

MCBECD（Minecraft Commands Documentation）是专注于**基岩版（Bedrock Edition）** Minecraft 命令的参考文档。

基岩版命令系统与 Java 版有许多差异——参数格式、返回值、可用命令均有不同。本文档以基岩版为准。

### 前提条件

- 在单人游戏中，需在**设置 → 游戏 → 作弊**中启用
- 在服务器中，需具备<strong>操作员（OP）</strong>权限
- 部分命令需要特定的 OP 等级（0-4）

### 命令执行

- 在聊天栏输入 `/` 后跟命令名称
- 命令方块中可直接输入命令（不需要前导 `/`）
- 使用 [`/execute`](./execute) 可以改变命令的执行上下文
- 命令区分大小写：全部小写

### 特性

- **基岩版专属命令** — 覆盖 `camera`、`ability`、`playanimation` 等独有命令
- **详细参数说明** — 每项参数的类型、可选值与用法
- **实用示例** — 直接可用的命令组合
