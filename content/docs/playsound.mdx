## `/playsound` — 播放音效

为指定玩家播放音效。所有音效必须通过玩家目标播放，基岩版不支持位置播放。

### 语法

`/playsound <音效> <玩家> [音量] [音高] [最小音量]`

### 参数

- `<音效>` — 音效事件标识符
- `<玩家>` — 目标玩家（必需参数）
- `[音量]` — 音量大小（0.0–2.0，默认：1.0）
- `[音高]` — 音高/音调（0.5–2.0，默认：1.0）
- `[最小音量]` — 远离音源时的最小音量（0.0–1.0）

### 常用音效 ID

| 音效 ID | 说明 |
|---------|------|
| `random.explode` | 爆炸声 |
| `random.levelup` | 经验升级 |
| `random.orb` | 经验球拾取 |
| `random.pop` | 弹出/物品拿取 |
| `random.click` | 按钮点击 |
| `random.anvil_land` | 铁砧落地 |
| `random.fizz` | 嘶嘶声（灭火/熔岩触水） |
| `random.eat` | 进食声 |
| `random.burp` | 打嗝声 |
| `random.drink` | 饮水声 |
| `random.chestopen` | 箱子打开 |
| `random.chestclosed` | 箱子关闭 |
| `random.door_open` | 门打开 |
| `random.door_close` | 门关闭 |
| `random.wood_click` | 木板点击 |
| `random.glass` | 玻璃碎裂 |
| `random.break` | 方块破坏 |
| `random.place` | 方块放置 |
| `random.splash` | 入水声 |
| `random.bowhit` | 箭击中 |
| `random.totem` | 不死图腾激活 |
| `ambient.weather.thunder` | 雷声 |
| `ambient.weather.rain` | 雨声 |
| `mob.zombie.villager.cure` | 僵尸村民治愈 |
| `mob.wither.spawn` | 凋灵生成 |
| `mob.enderdragon.growl` | 末影龙咆哮 |
| `note.harp` | 音符盒竖琴声 |
| `note.pling` | 音符盒叮咚声 |
| `note.bass` | 音符盒低音 |
| `fire.ignite` | 点火声 |

### 示例

**为最近玩家播放爆炸声：**
```mcfunction
/playsound random.explode @p
```

**为所有玩家播放升级音效：**
```mcfunction
/playsound random.levelup @a
```

**播放安静低音的音符声：**
```mcfunction
/playsound note.pling @p 0.5 0.5
```

**为最近玩家播放雷声（大音量）：**
```mcfunction
/playsound ambient.weather.thunder @p 2.0 1.0
```

**播放高音调的弹出声：**
```mcfunction
/playsound random.pop @p 1.0 2.0
```

### 基岩版注意

- 基岩版 `/playsound` **必须指定玩家**，不支持无目标的位置播放
- 音效从目标玩家的位置发出
- 音效 ID 体系与 Java 版有差异，部分音效在基岩版中不可用
- 音量和音高参数可超出推荐范围，但可能产生失真
- 需要 OP 等级 1
