## `/tp` — 传送

传送实体到指定坐标或目标实体。

### 语法

`/tp <目标> <位置>`

`/tp <目标> <目的地实体>`

`/tp <位置>`

### 参数

- `<目标>` — 被传送的实体
- `<位置>` — 目标坐标 `x y z`
- `<目的地实体>` — 传送到该实体所在位置

### 示例

```
/tp @p 100 64 100
```

将最近玩家传送到 (100, 64, 100)。

```
/tp @a @s
```

将所有玩家传送到执行者位置。

```
/tp 0 64 0
```

将自己传送到出生点附近。

```
/tp @p Steve
```

将最近玩家传送到 Steve 的位置。

### 注意事项

- 实体必须处于已加载的区块中
- 旋转角度保留（除非指定 `facing` 参数）
