## `/tp` — 传送

传送实体到指定坐标或目标实体。

### 语法

`/tp <目标> <位置>`

`/tp <目标> <目的地实体>`

`/tp <位置>`

`/tp <目标> <位置> <水平旋转> <垂直旋转>`

### 参数

- `<目标>` — 被传送的实体选择器
- `<位置>` — 目标坐标 `x y z`（支持相对和局部坐标）
- `<目的地实体>` — 传送到该实体所在位置
- `<水平旋转>` — 传送后的水平朝向角度（yaw，-180~180）
- `<垂直旋转>` — 传送后的垂直朝向角度（pitch，-90~90）

### 示例

```
/tp @p 100 64 100
```

将最近玩家传送到 (100, 64, 100)。

```
/tp @a @s
```

将所有玩家传送到执行者位置。

```
/tp 0 64 0
```

将自己传送到出生点附近。

```
/tp @p Steve
```

将最近玩家传送到 Steve 的位置。

```
/tp @s ~ ~5 ~ 90 0
```

将执行者向上传送 5 格，并朝向南方（水平旋转 90 度）。

```
/tp @a ~ ~ ~ 0 90
```

将所有玩家传送到当前位置不变，但强制朝向上方。

### 坐标说明

| 类型 | 格式 | 说明 |
|------|------|------|
| 绝对坐标 | `100 64 100` | 世界中的精确位置 |
| 相对坐标 | `~ ~1 ~` | 相对于当前位置偏移 |
| 局部坐标 | `^ ^ ^1` | 相对于视线方向 |

### 基岩版注意

- 实体必须处于已加载的区块中
- 传送到实体时，默认保持原有的朝向角度
- 可指定旋转角度来控制传送后的朝向
- 传送到 Y 轴负数位置或超出世界高度限制会失败
- 大量实体同时传送可能导致性能问题
- 需要 OP 等级 1
