## `/clone` — 克隆方块

将一个区域的方块复制到另一个位置。常用于复制建筑、批量建造和地图制作。

### 语法

`/clone <起点> <终点> <目标位置> [遮罩模式] [克隆模式] [方块过滤]`

### 参数

- `<起点>` `<终点>` — 源区域的两个对角坐标
- `<目标位置>` — 目标区域的西北下角坐标（最低 x、y、z）
- `[遮罩模式]` — 控制复制哪些方块
- `[克隆模式]` — 控制源区域和重叠区域的行为
- `[方块过滤]` — 当遮罩模式为 `filtered` 时，指定只复制的方块 ID

### 遮罩模式

| 模式 | 说明 |
|------|------|
| `replace` | 默认 — 复制源区域的所有方块（包括空气） |
| `masked` | 只复制非空气方块（空气不会被复制过去） |
| `filtered` | 只复制指定的方块类型 |

### 克隆模式

| 模式 | 说明 |
|------|------|
| `normal` | 默认 — 源区域和目标区域重叠时命令会失败 |
| `force` | 强制克隆，即使源区域和目标区域重叠也执行 |
| `move` | 复制后将源区域替换为空气（相当于剪切） |

### 示例

**克隆一个 5×5×5 的立方体：**
```mcfunction
/clone ~ ~ ~ ~4 ~4 ~4 100 64 0
```

**克隆建筑并移动到新位置（剪切模式）：**
```mcfunction
/clone ~ ~ ~ ~10 ~5 ~10 200 64 200 masked move
```

**只克隆非空气方块（保留目标区域的已有方块）：**
```mcfunction
/clone 0 60 0 10 70 10 50 64 50 masked
```

**只克隆特定方块（如只复制钻石块）：**
```mcfunction
/clone 0 0 0 10 10 10 50 64 50 filtered normal diamond_block
```

**强制克隆即使区域重叠：**
```mcfunction
/clone ~ ~ ~ ~5 ~5 ~5 ~10 ~ ~ force
```

### 基岩版注意

- 可克隆的最大方块数量有限制（32768），超出会失败
- 目标位置是区域的**西北下角**（最小 x、y、z 坐标）
- `move` 模式相当于复制 + 清除源区域，比单独执行两个命令更高效
- `masked` 模式下空气不会被复制，目标区域的原有方块保持不变
- 区域的源和目标重叠时需要使用 `force` 模式
- 克隆会保留方块的状态（如箱子内容物、告示牌文字、命令方块命令等）
- 建议：克隆大型结构前先备份世界存档
- 需要 OP 等级 1
