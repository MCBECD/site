## `/clone` — 克隆方块

将一个区域的方块复制到另一个区域。

### 语法

`/clone <起点> <终点> <目标位置> [遮罩模式] [克隆模式]`

### 参数

- `<起点>` `<终点>` — 源区域的对角坐标
- `<目标位置>` — 目标区域的西北下角坐标
- `[遮罩模式]` — 过滤要复制的方块：`replace`、`masked`、`filtered`
- `[克隆模式]` — 复制处理方式：`force`、`move`、`normal`
- `[方块名称]` — 当遮罩模式为 `filtered` 时必填
- `[方块数据]` — 过滤模式下的方块数据

### 遮罩模式

| 模式 | 说明 |
|------|------|
| `replace` | 复制所有方块（默认） |
| `masked` | 只复制非空气方块 |
| `filtered` | 只复制匹配 `[方块名称]` 的方块 |

### 克隆模式

| 模式 | 说明 |
|------|------|
| `force` | 强制克隆，即使区域重叠 |
| `move` | 复制方块后将源区域替换为空气 |
| `normal` | 默认模式 — 区域重叠时失败 |

### 示例

**克隆一个 5×5×5 的立方体：**
```mcfunction
/clone ~ ~ ~ ~4 ~4 ~4 100 64 0
```

**克隆一个建筑并移动到新位置：**
```mcfunction
/clone ~ ~ ~ ~10 ~5 ~10 200 64 200 replace move
```

**只克隆非空气方块：**
```mcfunction
/clone 0 60 0 10 70 10 50 64 50 masked
```

**只克隆钻石块：**
```mcfunction
/clone 0 0 0 10 10 10 50 64 50 filtered normal diamond_block
```

### 基岩版注意

- 可克隆的最大方块数量有限制，防止性能问题
- 目标位置是西北下角 — 确保有足够空间容纳复制的区域
- 使用 `move` 会在源区域留下空气方块
- 重叠区域可能需要 `force` 模式
- 需要 OP 等级 1
