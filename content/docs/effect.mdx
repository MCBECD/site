## `/effect` — 状态效果

给予或移除实体的状态效果。

### 语法

`/effect <目标> give <效果> [秒] [放大器] [隐藏粒子]`

`/effect <目标> clear`

`/effect <目标> clear <效果>`

### 参数

- `<目标>` — 目标选择器（`@p`、`@a`、`@s`、`@e`）
- `give` — 给予效果（子命令关键字）
- `<效果>` — 效果 ID（英文名称）
- `[秒]` — 持续时间（秒，默认 30）
- `[放大器]` — 效果等级（默认 0，即 I 级；1 表示 II 级，以此类推）
- `[隐藏粒子]` — `true` 隐藏粒子效果
- `clear` — 清除效果（不带效果名则清除全部）

### 常用效果

| 效果 ID | 说明 | 最大等级 |
|--------|------|----------|
| `speed` | 提高移动速度 | II (1) |
| `jump_boost` | 提高跳跃高度 | II (1) |
| `strength` | 增加近战伤害 | II (1) |
| `regeneration` | 持续恢复生命 | IV (3) |
| `invisibility` | 使实体不可见 | I (0) |
| `night_vision` | 在黑暗中看清 | I (0) |
| `resistance` | 减少受到的伤害 | IV (3) |
| `fire_resistance` | 免疫火焰伤害 | I (0) |
| `water_breathing` | 水下呼吸 | I (0) |
| `hunger` | 饥饿效果（负面） | I (0) |
| `poison` | 中毒（负面） | II (1) |
| `wither` | 凋零（负面） | II (1) |
| `slowness` | 减速（负面） | IV (3) |
| `weakness` | 虚弱（负面） | IV (3) |
| `absorption` | 伤害吸收 | IV (3) |
| `levitation` | 悬浮 | I (0) |
| `slow_falling` | 缓降 | I (0) |
| `conduit_power` | 潮涌能量 | I (0) |
| `darkness` | 黑暗效果 | I (0) |

### 示例

```
/effect @p give speed 30 1
```

给予最近玩家 30 秒速度 II。

```
/effect @p give night_vision 999999 0 true
```

给予永久夜视（隐藏粒子，约 578 小时）。

```
/effect @p clear
```

清除最近玩家的所有效果。

```
/effect @p clear speed
```

仅清除最近玩家的速度效果。

```
/effect @e[type=zombie] give slowness 30 2 true
```

给所有僵尸 30 秒减速 III（隐藏粒子）。

### 基岩版注意

- 效果 ID 使用英文名称，不是数字
- 基岩版语法为 `/effect <target> give <effect> ...`，注意 `give` 子命令关键字是**必需的**
- `clear` 子命令可以清除全部效果或指定效果
- 放大器从 0 开始（0 = I 级，1 = II 级，2 = III 级）
- 需要 OP 等级 1
