## `/weather` — 天气控制

设置游戏天气。

### 语法

`/weather <类型> [持续时间]`

### 天气类型

| 类型 | 说明 |
|------|------|
| `clear` | 晴天 |
| `rain` | 下雨 |
| `thunder` | 雷暴 |

### 参数

- `[持续时间]` — 天气持续时间（游戏刻，1秒=20刻），默认随机（下雨 3000-6000 刻，雷暴 3000-6000 刻，最大 1000000 刻）

### 示例

```
/weather clear
```

设置为晴天。

```
/weather rain 6000
```

设置 5 分钟的下雨（6000 刻 = 300 秒 = 5 分钟）。

```
/weather thunder
```

设置为雷暴天气。

```
/weather clear 1000000
```

永久晴天。

### 基岩版注意

- 持续时间单位为**游戏刻**（tick），不是秒。1 秒 = 20 刻
- 晴天也会自然结束，使用大数值可近似实现永久晴天
- 需要 OP 等级 1
