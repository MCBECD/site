## `/fill` — 填充方块

用指定方块填充一个区域。

### 语法

`/fill <起点> <终点> <方块> [数据值] [模式]`

`/fill <起点> <终点> <方块> [数据值] replace [被替换方块]`

### 参数

- `<起点>` `<终点>` — 矩形区域的对角坐标

### 模式

| 模式 | 说明 |
|------|------|
| `destroy` | 破坏区域内方块，掉落物品 |
| `hollow` | 仅填充外层，内部留空 |
| `keep` | 仅替换空气方块 |
| `outline` | 同 hollow |
| `replace` | 默认，替换所有方块 |

### 示例

```
/fill ~-5 ~-1 ~-5 ~5 ~-1 ~5 stone
```

填充脚下的 11×11 石头地板。

```
/fill 0 64 0 10 70 10 air
```

清除一个 10×6×10 区域。

```
/fill ~ ~ ~ ~10 ~ ~10 glass hollow
```

创建玻璃盒子。
