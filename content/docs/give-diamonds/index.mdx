## 命令

以下命令可一次性给予执行者全套附魔钻石装备，包含武器、工具和防具。请在聊天栏中逐条执行：

```mcfunction
/give @s diamond_sword 1 0 {"enchantments":[{"id":"sharpness","level":5},{"id":"unbreaking","level":3},{"id":"looting","level":3}]}
/give @s diamond_pickaxe 1 0 {"enchantments":[{"id":"efficiency","level":5},{"id":"unbreaking","level":3},{"id":"fortune","level":3}]}
/give @s diamond_axe 1 0 {"enchantments":[{"id":"efficiency","level":5},{"id":"unbreaking","level":3}]}
/give @s diamond_shovel 1 0 {"enchantments":[{"id":"efficiency","level":5},{"id":"unbreaking","level":3},{"id":"fortune","level":3}]}
/give @s diamond_helmet 1 0 {"enchantments":[{"id":"protection","level":4},{"id":"unbreaking","level":3},{"id":"mending","level":1}]}
/give @s diamond_chestplate 1 0 {"enchantments":[{"id":"protection","level":4},{"id":"unbreaking","level":3},{"id":"mending","level":1}]}
/give @s diamond_leggings 1 0 {"enchantments":[{"id":"protection","level":4},{"id":"unbreaking","level":3},{"id":"mending","level":1}]}
/give @s diamond_boots 1 0 {"enchantments":[{"id":"protection","level":4},{"id":"unbreaking","level":3},{"id":"feather_falling","level":4},{"id":"mending","level":1}]}
```

## 说明

- **钻石剑**：锋利 V + 耐久 III + 抢夺 III — 最高近战输出
- **钻石镐**：效率 V + 耐久 III + 时运 III — 最佳挖矿工具
- **钻石斧**：效率 V + 耐久 III — 快速伐木
- **钻石铲**：效率 V + 耐久 III + 时运 III — 挖掘沙砾等
- **钻石头盔**：保护 IV + 耐久 III + 经验修补
- **钻石胸甲**：保护 IV + 耐久 III + 经验修补
- **钻石护腿**：保护 IV + 耐久 III + 经验修补
- **钻石靴子**：保护 IV + 耐久 III + 摔落保护 IV + 经验修补

### 基岩版注意

- 以上命令使用旧版附魔组件语法，适用于基岩版 1.20.50 以下版本
- 在 1.20.50+ 版本中，物品组件语法有较大变更，建议查阅对应版本文档
- 附魔等级超过正常上限（如锋利 5）在命令中是允许的，但效果有上限
- 需要 OP 等级 1
