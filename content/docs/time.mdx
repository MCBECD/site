## `/time` — 时间控制

查询或设置游戏内时间。

### 语法

`/time set <值>`

`/time add <值>`

`/time query <类型>`

### 时间值

| 值 | 对应时间 |
|------|------|
| `0` | 日出（6:00） |
| `1000` | 上午 |
| `6000` | 正午（12:00） |
| `12000` | 日落（18:00） |
| `18000` | 午夜（0:00） |
| `day` | 日出 |
| `noon` | 正午 |
| `night` | 午夜 |

### query 类型

| 类型 | 说明 |
|------|------|
| `daytime` | 当天游戏时间（0-24000） |
| `gametime` | 世界总游戏时间 |
| `day` | 已过的游戏天数 |

### 示例

`/time set day`

设为白天。

`/time add 1000`

时间前进 1000 刻。

`/time set 6000`

`/gamerule doDaylightCycle false`

设为正午并锁定时间。

`/time query daytime`

查询当前游戏时间。
