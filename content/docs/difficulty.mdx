## `/difficulty` — 难度设置

设置游戏难度等级。

### 语法

`/difficulty <等级>`

### 难度等级

| 等级 | 数字 | 说明 |
|------|------|------|
| `peaceful` | `0` | 和平 — 无怪物，自动回血 |
| `easy` | `1` | 简单 — 怪物伤害较低 |
| `normal` | `2` | 普通 — 标准难度 |
| `hard` | `3` | 困难 — 怪物伤害高，僵尸破门 |

### 示例

```
/difficulty peaceful
```

设为和平模式。

```
/difficulty 2
```

设为普通难度。

```
/difficulty hard
```

设为困难难度。

### 基岩版注意

- 难度影响怪物生成、伤害值和行为
- 困难难度下僵尸可以破门
- 和平模式下已有怪物不会消失，但不会新生成
- 难度可在世界设置中永久更改
- 需要 OP 等级 1
