## `/gamerule` — 游戏规则

设置或查询世界游戏规则。

### 语法

`/gamerule <规则> [值]`

`/gamerule <规则>`

不带值则查询当前设置。

### 常用规则

| 规则 | 默认 | 说明 |
|------|------|------|
| `keepInventory` | `false` | 死亡不掉落物品 |
| `doDaylightCycle` | `true` | 昼夜循环 |
| `doMobSpawning` | `true` | 生物生成 |
| `doFireTick` | `true` | 火焰蔓延 |
| `mobGriefing` | `true` | 生物破坏方块 |
| `showCoordinates` | `false` | 显示坐标 |
| `commandBlocksEnabled` | `true` | 启用命令方块 |

### 示例

```
/gamerule keepInventory true
```

死亡后保留物品。

```
/gamerule doDaylightCycle false
```

锁定昼夜循环。

```
/gamerule showCoordinates true
```

在屏幕显示坐标。

### 基岩版注意

- 布尔值规则：`true` 开启，`false` 关闭
- `showCoordinates` 是基岩版独有规则，Java 版没有
- `commandBlocksEnabled` 控制命令方块是否可执行
- 部分规则需要退出并重新进入世界才能生效
- 可使用 `/gamerule <规则>`（不带值）查询当前设置
- 需要 OP 等级 1
