## `/xp` — 经验值

给予玩家经验值或经验等级。用于快速获取经验，方便附魔和修理。

### 语法

`/xp <数量> [玩家]`

`/xp <数量>L [玩家]`

### 参数

- `<数量>` — 要给予的经验值点数
- `<数量>L` — 要给予的经验等级（带 `L` 后缀表示等级而非点数）
- `[玩家]` — 目标玩家（默认：执行者自身）

### 示例

**给自己 100 经验值：**
```mcfunction
/xp 100 @s
```

**给最近玩家 5 级经验：**
```mcfunction
/xp 5L @p
```

**给所有玩家 30 级经验：**
```mcfunction
/xp 30L @a
```

**给自己 1 级经验：**
```mcfunction
/xp 1L
```

### 经验机制

- 经验值（XP）累积用于提升等级
- 等级越高，升级所需的经验值越多
- 获取经验的自然方式：击杀生物、挖矿、烧炼、交易等
- 经验可用于铁砧附魔、修理和重命名
- 在基岩版中，`/xp` 只能**给予**经验，不能设定或查询
- `L` 后缀区分大小写（小写 `l` 无效）
- 可以给予负数经验来扣除经验值（但不推荐，可能导致意外行为）

### 基岩版与 Java 版区别

- 基岩版**没有** `/xp query` 子命令
- 基岩版**没有** `/xp set` 子命令
- 基岩版只能使用正数或负数给予/扣除经验值
- 如需精确控制等级，可配合计分板使用

### 基岩版注意

- 需要 OP 等级 1
