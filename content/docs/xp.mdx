## `/xp` — 经验值

添加、设置或查询玩家经验值和等级。

### 语法

`/xp <数量> [玩家]`

`/xp <数量>L [玩家]`

### 参数

- `<数量>` — 要添加的经验值点数
- `<数量>L` — 要添加的经验等级数（加 `L` 后缀表示等级）
- `[玩家]` — 目标玩家（默认：执行者自身）

### 示例

**给自己 100 经验值：**
```mcfunction
/xp 100 @s
```

**给最近玩家 5 级经验：**
```mcfunction
/xp 5L @p
```

**给所有玩家 30 级经验：**
```mcfunction
/xp 30L @a
```

**给自己 1 级经验：**
```mcfunction
/xp 1L
```

**给特定玩家多级经验：**
```mcfunction
/xp 50L Steve
```

### 经验机制

- 经验值（XP）累积用于提升等级
- 更高等级需要更多经验值
- 经验球是获取经验的自然方式（击杀生物、挖矿、烧炼）
- 在铁砧中附魔、修复和重命名需要消耗经验等级
- 最高等级为 24791（需要 2147483647 总经验值）
- 30 级需要 1395 总经验值

### 基岩版注意

- 基岩版中 `/xp` 只能添加经验 — 不能直接设定或查询
- 可使用 `/xp` 加负数来减去经验（不推荐，谨慎使用负值）
- 基岩版没有专门的 `/xp query` 或 `/xp set` 子命令
- 经验无法直接设置为特定等级 — 使用计分板数学进行复杂的经验管理
- `L` 后缀区分大小写
- 需要 OP 等级 1
