## `/summon` — 生成实体

在指定位置生成实体。

### 语法

`/summon <实体类型> [位置] [事件] [名称]`

### 参数

- `<实体类型>` — 实体 ID
- `[位置]` — 生成坐标（默认执行位置）
- `[事件]` — 实体生成事件
- `[名称]` — 自定义名称

### 示例

`/summon zombie ~ ~ ~`

在当前位置生成僵尸。

`/summon creeper 100 64 100`

在指定坐标生成苦力怕。

`/summon lightning_bolt ~ ~10 ~`

在头顶 10 格生成闪电。

### 常用实体 ID

| 实体 | ID |
|------|-----|
| 僵尸 | `zombie` |
| 骷髅 | `skeleton` |
| 苦力怕 | `creeper` |
| 末影龙 | `ender_dragon` |
| 村民 | `villager` |
| TNT | `tnt` |
