## `/gamemode` — 游戏模式

切换玩家的游戏模式。

### 语法

`/gamemode <模式> [玩家]`

`/gamemode <数字> [玩家]`

### 模式参数

| 模式 | 数字 | 说明 |
|------|------|------|
| `creative` | `1` | 创造模式 — 无限资源，可飞行 |
| `survival` | `0` | 生存模式 — 需要收集资源，有生命值 |
| `adventure` | `2` | 冒险模式 — 不能破坏方块，用于自定义地图 |
| `spectator` | `n/a` | **基岩版不支持旁观模式** |

### 示例

```
/gamemode creative @p
```

将最近的玩家设为创造模式。

```
/gamemode survival @a
```

将所有玩家设为生存模式。

```
/gamemode 1
```

将所有玩家设为生存模式。

```
/gamemode 1
```

### 基岩版注意

- 基岩版没有旁观模式
- 默认模式可在世界设置中更改
- 需要 OP 等级 1
