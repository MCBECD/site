## `/gamemode` — 游戏模式

切换玩家的游戏模式。

### 语法

`/gamemode <模式> [玩家]`

`/gamemode <数字> [玩家]`

### 模式参数

| 模式 | 数字 | 说明 |
|------|------|------|
| `survival` | `s` / `0` | 生存模式 — 需要收集资源，有生命值 |
| `creative` | `c` / `1` | 创造模式 — 无限资源，可飞行 |
| `adventure` | `a` / `2` | 冒险模式 — 不能破坏方块，用于自定义地图 |
| `spectator` | `sp` / `6` | 旁观模式 — 可穿过方块观察，部分版本可用 |

### 示例

```
/gamemode creative @p
```

将最近的玩家设为创造模式。

```
/gamemode survival @a
```

将所有玩家设为生存模式。

```
/gamemode c
```

将自己设为创造模式（使用缩写）。

```
/gamemode spectator
```

将执行者设为旁观模式。

### 基岩版注意

- 基岩版从 1.19.50 开始支持旁观模式（spectator），但功能比 Java 版有限
- 旁观模式下无法使用物品和方块交互
- 默认模式可在世界设置中更改
- 需要 OP 等级 1
