## `/give` — 给予物品

给予玩家指定物品。

### 语法

`/give <玩家> <物品> [数量] [数据值] [组件]`

### 参数

- `<玩家>` — 目标选择器
- `<物品>` — 物品 ID（如 `diamond`、`stone`）
- `[数量]` — 数量（1-64，默认 1）
- `[数据值]` — 物品的辅助数据值
- `[组件]` — JSON 格式的物品组件

### 示例

`/give @p diamond 64`

给予最近玩家 64 个钻石。

`/give @a diamond_sword 1`

给予所有玩家一把钻石剑。

`/give @p stone 1 1`

给予花岗岩（数据值 1=花岗岩，0=石头）。

### 常用物品 ID

| 物品 | ID |
|------|-----|
| 钻石 | `diamond` |
| 钻石剑 | `diamond_sword` |
| 金苹果 | `golden_apple` |
| 命令方块 | `command_block` |
| 基岩 | `bedrock` |
