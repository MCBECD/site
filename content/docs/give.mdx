## `/give` — 给予物品

给予玩家指定物品。基岩版 1.20.50+ 已弃用旧版数据值语法，改用物品组件系统。

### 语法

**新版语法（1.20.50+）：**

`/give <玩家> <物品> [数量] [组件]`

**旧版语法（1.20.50 以下）：**

`/give <玩家> <物品> [数量] [数据值] [组件]`

### 参数

- `<玩家>` — 目标选择器
- `<物品>` — 物品 ID（如 `diamond`、`stone`、`granite`）
- `[数量]` — 数量（1-64，默认 1）
- `[数据值]` — 旧版物品变体数据值（已弃用，1.20.50+ 应使用独立物品 ID）
- `[组件]` — JSON 格式的物品组件

### 物品组件

基岩版使用 JSON 格式的物品组件来定义额外属性，常见组件包括：

| 组件 | 说明 |
|------|------|
| `"enchantments"` | 附魔列表 |
| `"display_name"` | 自定义物品名称 |
| `"lore"` | 物品描述 |
| `"item_lock"` | 物品锁定模式 |
| `"keep_on_death"` | 死亡后保留 |
| `"damage"` | 物品耐久值 |
| `"count"` | 物品数量（组件内） |

### 示例

```
/give @p diamond 64
```

给予最近玩家 64 个钻石。

```
/give @a diamond_sword 1
```

给予所有玩家一把钻石剑。

```
/give @p stone 64
```

给予石头（在 1.20.50+ 中石头就是 `stone`，花岗岩使用独立 ID `granite`）。

```
/give @s diamond_sword 1 0 {"enchantments":[{"id":"sharpness","level":5}]}
```

给予一把锋利 V 钻石剑（使用旧版组件语法）。

```
/give @s golden_apple 1 0 {"item_lock":"lock_in_inventory"}
```

给予一个锁定在物品栏中的金苹果。

### 常用物品 ID

| 物品 | ID |
|------|-----|
| 钻石 | `diamond` |
| 钻石剑 | `diamond_sword` |
| 金苹果 | `golden_apple` |
| 附魔金苹果 | `enchanted_golden_apple` |
| 命令方块 | `command_block` |
| 基岩 | `bedrock` |
| 花岗岩 | `granite` |
| 闪长岩 | `diorite` |
| 安山岩 | `andesite` |

### 基岩版注意

- 1.20.50+ 版本弃用了物品数据值，改用独立物品 ID（如花岗岩从 `stone 1` 变为 `granite`）
- 物品组件语法在近期版本中有较大变化，建议查阅对应版本的 Wiki
- 旧版命令中使用数据值 0 的物品可省略数据值参数
- 需要 OP 等级 1
