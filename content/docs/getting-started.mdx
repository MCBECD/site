## 快速开始

### 启用作弊

使用命令前需要先启用世界中的作弊选项：

1. 打开 **设置 → 游戏**
2. 将 **作弊** 开关设为 **开启**

启用后成就将被永久禁用。服务器中可用 [`/op`](./gamemode) 授予操作员权限。

### 你的第一条命令

打开聊天栏，输入 `/`，然后试试：

[`/give @s diamond 64`](./give)

这会给自己 64 个钻石。`@s` 表示「执行者自己」。更多选择器用法见 [命令语法基础](./command-syntax)。

### 命令方块

命令方块可以自动化执行命令，是制作地图和小游戏的核心工具。

[`/give @s command_block`](./give)

放置后右键打开，输入命令（不需要 `/`），选择执行方式：

- **脉冲** — 收到红石信号执行一次
- **重复** — 每个游戏刻循环执行
- **连锁** — 在指向它的命令方块执行后触发

### 常用操作

- [`/time set day`](./time) — 设为白天
- [`/weather clear`](./weather) — 清除雨天
- [`/gamemode creative`](./gamemode) — 切换创造
- [`/kill @e[type=item]`](./kill) — 清除掉落物
