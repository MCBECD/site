## `/kill` — 清除实体

清除（杀死）指定实体。对玩家造成致命伤害，对生物直接移除。

### 语法

`/kill [目标]`

### 参数

- `[目标]` — 目标选择器（默认执行者自己）

### 示例

```
/kill @e[type=zombie]
```

清除所有僵尸。

```
/kill @e[type=item]
```

清除所有掉落物。

```
/kill @e[type=!player]
```

清除除玩家外的所有实体。

```
/kill
```

清除自己（对自身造成致命伤害）。

### 基岩版注意

- `/kill` 对玩家造成致命伤害，玩家会被直接击杀
- 对非玩家实体直接移除（不产生掉落物和死亡动画）
- 使用 `@e[type=item]` 可清除地上的掉落物
- 使用 `@e[type=!player]` 可清除所有非玩家实体
- 在没有指定目标时，执行者自身受到致命伤害
- 需要 OP 等级 1
