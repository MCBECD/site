## `/enchant` — 附魔物品

为玩家手持或主手栏中的物品添加附魔。

### 语法

`/enchant <玩家> <附魔ID> <等级>`

### 参数

- `<玩家>` — 目标玩家（必须手持可附魔的物品）
- `<附魔ID>` — 附魔标识符（英文名称，如 `sharpness`）
- `<等级>` — 附魔等级（从 1 开始；1 = I 级，2 = II 级，以此类推）

> 注意：基岩版中等级参数是**必填的**，即使附魔 I 级也需要写等级 1。

### 示例

**为手持物品附魔锋利 V：**
```mcfunction
/enchant @p sharpness 5
```

**为最近玩家的手持物品附魔效率 V：**
```mcfunction
/enchant @p efficiency 5
```

**应用精准采集：**
```mcfunction
/enchant @s silk_touch 1
```

**给所有玩家耐久 III：**
```mcfunction
/enchant @a unbreaking 3
```

**为手持头盔附魔水下呼吸 III：**
```mcfunction
/enchant @p respiration 3
```

### 基岩版注意

- 玩家必须手持要附魔的物品（主手栏）
- 物品必须支持该附魔，否则命令会失败
- 不兼容的附魔（如同时有锋利和亡灵杀手）不能共存
- 可以通过命令应用超过正常上限的附魔等级（例如锋利 100），但实际效果有上限
- `/enchant` 只能给玩家手中的物品附魔，不能给掉落物或容器中的物品附魔
- 需要 OP 等级 1
