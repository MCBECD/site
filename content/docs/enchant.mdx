## `/enchant` — 附魔物品

为玩家手持的物品添加附魔。

### 语法

`/enchant <玩家> <附魔ID> [等级]`

### 参数

- `<玩家>` — 目标玩家
- `<附魔ID>` — 附魔标识符
- `[等级]` — 附魔等级（默认：1）

### 常用附魔

| 附魔名称 | ID | 最大等级 | 适用物品 |
|----------|----|---------|---------|
| 锋利 | `sharpness` | 5 | 剑、斧 |
| 亡灵杀手 | `smite` | 5 | 剑、斧 |
| 保护 | `protection` | 4 | 盔甲 |
| 效率 | `efficiency` | 5 | 工具 |
| 耐久 | `unbreaking` | 3 | 所有物品 |
| 时运 | `fortune` | 3 | 镐、铲 |
| 精准采集 | `silk_touch` | 1 | 工具 |
| 力量 | `power` | 5 | 弓 |
| 火矢 | `flame` | 1 | 弓 |
| 无限 | `infinity` | 1 | 弓 |
| 抢夺 | `looting` | 3 | 剑 |
| 击退 | `knockback` | 2 | 剑 |
| 火焰附加 | `fire_aspect` | 2 | 剑 |
| 经验修补 | `mending` | 1 | 所有物品 |
| 忠诚 | `loyalty` | 3 | 三叉戟 |
| 激流 | `riptide` | 3 | 三叉戟 |

### 示例

**为手持物品附魔锋利 V：**
```mcfunction
/enchant @p sharpness 5
```

**为最近玩家的手持物品附魔效率 IV：**
```mcfunction
/enchant @p efficiency 4
```

**应用精准采集：**
```mcfunction
/enchant @s silk_touch 1
```

**给所有玩家耐久 III：**
```mcfunction
/enchant @a unbreaking 3
```

### 基岩版注意

- 玩家必须手持要附魔的物品
- 不兼容的附魔会覆盖物品上已有的附魔
- 可以应用超过正常上限的附魔等级（例如锋利 100）
- 需在世界设置 → 游戏 → 作弊中启用作弊
- 需要 OP 等级 1
